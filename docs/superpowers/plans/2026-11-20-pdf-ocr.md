# PDF OCR Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** PDF 按原阅读顺序逐页输出自包含 Markdown。
**Architecture:** 配置 → OCR JSON 布局 → 图片裁剪与 Markdown → 逐页 CLI。
**Tech Stack:** Python、PyMuPDF、Pillow、HTTPX、Pydantic Settings、pytest。
**Spec:** ../specs/2026-11-20-pdf-ocr-design.md

## Global Constraints
- 页码从 1 开始；output/<stem>/<page>/<page>.md。
- 密钥只在 .env；保留模型内容块顺序；图片为 PNG Base64。

## Review Focus
- 双栏内容不能按坐标交错排序：渲染测试检验数组顺序。
- 扫描件插图及旋转页：裁剪测试与真实 PDF 渲染测试。
- 模型截断或坏坐标：客户端和 schema 负向用例。
- 部分页失败：manifest 和非零状态验证。
- 旧输出混入或覆盖：拒绝已存在目录测试。
