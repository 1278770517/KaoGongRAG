# 项目检索服务与图片引用

依据：PRD 第 13 节及用户确认的图片存储方向。范围：将五页实验升级为可维护的导入与检索服务，不增加缓存、不继续 OCR 全书。

## 实现方向

采用 FastAPI + PostgreSQL 父题/资源记录 + Milvus 双向量索引 + 本地独立图片文件。相比继续扫描 parents.json，数据库支持批量回表及版本核验；不把图片二进制放进 Milvus，避免向量查询搬运图片。原始 OCR、现有测试集合和用户未提交改动保留。

导入阶段按布局裁剪一次，生成内容寻址 asset_id，持久化文件、来源页和 bbox。Milvus chunk 冗余 image_asset_ids，查询返回稳定图片地址；题目与资源的权威关联在 PostgreSQL。图片读取不现场裁剪，不返回 Base64。初期资源仅在本机部署范围内开放，不宣称已有互联网多租户鉴权。

拆分 ingestion、providers、repositories、retrieval、api 模块，保留可运行 CLI。模型和连接配置独立于 OCR 配置，允许显式复用现有百炼地址和密钥；取消实验脚本向量缓存。模型输入使用匹配 tokenizer 控制长度，长证据按语义段切分并保留题干条件。缺页、图像信息不足、末页截断保留审核状态。

检索提供 BM25、dense 与 RRF 混合召回，按父题聚合；一次批量回查题目、版本和图片关联。提供检索、题目详情、资源读取和健康检查接口。练习前提示不暴露解析，开发审核查询与默认已发布查询分开。Reranker、作答判题、缓存和全书 OCR 不在本轮范围。

## 并发与失败处理

外部 embedding 用异步 HTTP 客户端，PostgreSQL 用异步连接池；Milvus 查询优先验证 SDK 的异步接口。只能同步执行的 SDK、文件和裁剪操作进入有界工作线程，CPU 密集导入与 HTTP 请求分开。连接在 lifespan 初始化及关闭，不为每条请求新建客户端。

设置连接/请求超时、连接池和并发上限、有限重试与取消传播。不得跨外部 API 调用持有数据库事务或锁；不得在 asyncio 事件循环内运行同步网络请求或嵌套 asyncio.run。异步不等于杜绝死锁，验证并发隔离、资源释放和失败恢复。

PostgreSQL 短事务保存父题与索引任务，独立导入 worker 执行 Milvus 幂等写入；确认计数和检索后记录可用状态，防止部分写入被当作发布成功。重试不重复生成资源和题目。

## 验证

测试跨页与选项/答案配对、图片坐标和路径安全、关联完整性、重复导入、向量返回映射、并发超时、取消与单路降级、审核/版本过滤。实际用五页样本验证混合召回、图片 URL 返回和图片读取，并保留测试报告；不以少量并发测试承诺任意吞吐。

## 当前待补充的部署信息

本地仅发现 OCR 环境配置，没有 PostgreSQL 连接配置。需要确认 PostgreSQL 主机、端口、库名和用户名；密码写本地 .env，不进入聊天或版本库。在确认前不擅自创建或修改未知业务数据库。
